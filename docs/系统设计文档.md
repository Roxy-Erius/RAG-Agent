# AI 购物助手 — 系统设计文档

> 基于 RAG 的多模态电商智能导购 AI Agent

## 一、项目概述

### 1.1 项目简介

AI 购物助手是一个基于 RAG（检索增强生成）技术的电商智能导购系统。用户通过 Android App 以自然语言描述购物需求，后端利用 LangChain4j + ChromaDB + 豆包大模型进行语义理解、商品检索和个性化推荐，并通过 SSE 流式返回 AI 回复和商品卡片。

### 1.2 技术栈

| 层次 | 技术 | 版本 |
|------|------|------|
| 客户端 | Android (Kotlin), ViewBinding, OkHttp SSE, Gson, Glide, Coroutines | API 26+, AGP 9.0.1 |
| 后端 | Spring Boot, Java 17, Maven | 3.2.5 |
| AI 框架 | LangChain4j | 0.36.2 |
| 向量库 | ChromaDB (Docker) | latest |
| 关系库 | MySQL | 8.0 |
| LLM | 豆包 Doubao-Seed-2.0-lite | — |
| Embedding | 豆包 Doubao-embedding-vision | — |

### 2.2 核心数据流

```
Android "推荐一款适合油皮的洗面奶"
  → SSE GET /api/chat/stream
    → ChatService.chatStream()
      → LangChain4j AiServices 自动编排:
         1. userMessage → Embedding → ChromaDB.query() → Top-3 商品
         2. 组装 System Prompt + 检索上下文 + ChatMemory 历史
         3. Doubao LLM 流式生成
         4. flushSseBuffer() 检测 [PRODUCT:id] 标签
            → SSE token 事件 (逐字文本)
            → SSE product 事件 (商品卡片触发)
         5. 检测 [ADD_TO_CART:id] / [DELETE_FROM_CART:id] 标签
            → SSE add_to_cart / delete_from_cart 事件
         6. 检测 [DONE] → SSE done 事件
    → Android SseClient 接收
      → ChatViewModel 分发:
         - Token → updateLastAiMessage()
         - ProductRef → pendingProductIds (DONE 时批量拉取)
         - AddToCart → apiService.addToCart()
         - Done → fetchAndInsertProductCards()
      → ChatAdapter 渲染:
         - 用户消息 (灰色气泡)
         - AI 文本 (流式追加)
         - 商品卡片 (图片 + 名称 + 价格 + 加购按钮)
```

## 三、数据库设计

### 3.1 表结构

```sql
-- 商品主表
CREATE TABLE products (
    product_id VARCHAR(50) PRIMARY KEY,
    title VARCHAR(300) NOT NULL,
    brand VARCHAR(100) NOT NULL,
    category VARCHAR(50) NOT NULL,
    sub_category VARCHAR(50) NOT NULL,
    base_price DECIMAL(10,2) NOT NULL,
    image_path VARCHAR(200) DEFAULT '',
    marketing_description TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- SKU 表
CREATE TABLE product_skus (
    sku_id VARCHAR(50) PRIMARY KEY,
    product_id VARCHAR(50) NOT NULL,
    properties JSON,
    price DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (product_id) REFERENCES products(product_id)
);

-- FAQ 表
CREATE TABLE product_faqs (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    product_id VARCHAR(50) NOT NULL,
    question VARCHAR(500) NOT NULL,
    answer TEXT NOT NULL,
    FOREIGN KEY (product_id) REFERENCES products(product_id)
);

-- 用户评价表
CREATE TABLE product_reviews (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    product_id VARCHAR(50) NOT NULL,
    nickname VARCHAR(50) NOT NULL,
    rating INT NOT NULL,
    content TEXT NOT NULL,
    FOREIGN KEY (product_id) REFERENCES products(product_id)
);

-- 购物车表
CREATE TABLE cart_items (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    session_id VARCHAR(50),
    user_id BIGINT,
    product_id VARCHAR(50) NOT NULL,
    sku_id VARCHAR(100),
    sku_label VARCHAR(500),
    quantity INT DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 用户行为表
CREATE TABLE user_behaviors (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    product_id VARCHAR(50) NOT NULL,
    action_type VARCHAR(20) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 用户表
CREATE TABLE users (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(200) NOT NULL,
    nickname VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 会话表
CREATE TABLE conversations (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    conversation_id VARCHAR(36) NOT NULL UNIQUE,
    title VARCHAR(100),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 消息表
CREATE TABLE messages (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    conversation_id BIGINT NOT NULL,
    role VARCHAR(10) NOT NULL,
    content TEXT,
    product_ids VARCHAR(500),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 ER 关系

```
users 1──N conversations
users 1──N user_behaviors
users 1──N cart_items (via user_id)

conversations 1──N messages

products 1──N product_skus
products 1──N product_faqs
products 1──N product_reviews
products 1──N cart_items (via product_id)
products 1──N user_behaviors

product_skus 1──N cart_items (via sku_id)
```

## 五、RAG 管道设计

### 5.1 知识库构建

```
MySQL products 表 (100 条)
  → 拼接文本:
    "{title} {category} {sub_category} {brand} {base_price}元 {marketing_description}"
  → Doubao-embedding-vision API
  → 1024 维向量
  → ChromaDB collection: "products"
  → 附加 Metadata: productId
```

### 5.2 检索增强生成

```
用户消息
  → Embedding
  → ChromaDB.query() — cosine 相似度, Top-3
  → 相似度过滤 (minScore >= 0.5)
  → System Prompt 模板:
     """
     你是专业电商导购助手。
     规则: 只推荐商品库中存在的商品，不编造信息，回复简洁适合移动端。
     推荐商品时插入 [PRODUCT:id] 标记。
     
     商品库: {top-3 检索结果}
     对话历史: {ChatMemory 最近 10 条}
     """
  → Doubao-Seed-2.0-lite 流式生成
  → SseEmitter 逐 token 推送
```

### 5.3 防幻觉策略（三层）

| 层 | 策略 | 说明 |
|---|------|------|
| Prompt 级 | System Prompt 硬约束 | 禁止推荐不存在商品 |
| 检索级 | minScore 阈值过滤 | 相似度过低不注入上下文 |
| 后处理 | [PRODUCT:id] ID 校验 | 验证 ID 是否在检索结果中 |

### 6.3 SpecSheetDialog 设计

```
弹出层: BottomSheetDialogFragment

内容结构:
  ┌──────────────────┐
  │  拖拽手柄          │
  │  [图] ¥价格        │
  │  已选: 规格标签    │
  │                    │
  │  颜色              │
  │  [深空灰✓][星河银] │  ← 按维度分组
  │                    │
  │  存储              │
  │  [256GB✓][512GB]   │
  │                    │
  │  数量  [−] 1 [+]   │  ← 1-99
  │                    │
  │  [═════ 确定 ═════] │  ← 加入购物车

  → 选择时交叉匹配: 选中值 → 查找匹配 SKU → 更新价格
```

## 七、关键功能

### 7.1 个性化推荐系统

| 版本 | 策略 | 降级 |
|------|------|------|
| V3 行为加权 | VIEW×1.0 / CART×3.0 / PURCHASE×5.0 × e^(-0.05·days) | → V2 |
| V2 语义检索 | 历史消息 Embedding → ChromaDB 语义检索 Top 3 | → V1 |
| V1 关键词 | 历史消息品类关键词 → 随机 3 条 | — |

### 7.2 购物车 SKU 支持

- `cart_items` 表按 `(product_id, sku_id)` 去重
- 不同 SKU 独立成行，分别计算数量和价格
- JOIN `product_skus` 取 SKU 专属价格: `COALESCE(s.price, p.base_price)`
- 前端展示：商品名 + 规格小字（无 SKU 显示"标准"）

### 7.3 对话驱动购物车

- LLM 通过 `[ADD_TO_CART:id:N]` / `[DELETE_FROM_CART:id]` / `[CLEAR_CART]` 标签操作购物车
- SSE 流中实时检测标签，发送结构化 JSON 事件
- `flushSseBuffer()` 累积 token 直到检测到完整标签
- `isIncompleteTag()` 保护未完成标签不被误发

### 7.4 用户认证

- JWT 令牌认证 (jjwt 0.12.5 + BCrypt)
- 匿名会话支持（sessionId），登录后可迁移: `migrateSessionToUser()`
- OkHttp 拦截器自动附加 Authorization header
- 购物车/历史会话需要登录

### 7.5 会话持久化

- 登录用户消息写入 MySQL (conversations + messages)
- `product_ids` JSON 字段存储商品引用
- 加载历史时批量 `getProductsBatch()` 还原卡片
- 正则清除历史消息中的 `[PRODUCT:id]` 等标签
