# 云服务器部署指南 — Docker + MySQL + ChromaDB

> 三人共用一台服务器，本地只写代码，通过 Git 同步。

---

## 前置条件

- 有服务器公网 IP 和 root 密码
- 本地有 SSH 工具（Windows 自带 cmd / PowerShell 都支持）

---

## 第一步：SSH 连接服务器

```bash
ssh root@你的公网IP
```

输入密码（输入时不会显示字符，正常现象），回车连接。

成功后命令行变成 `root@xxx:~#`，表示已在服务器上。

---

## 第二步：安装 Docker

**Ubuntu / Debian：**

```bash
apt update
apt install -y docker.io
systemctl start docker
systemctl enable docker
docker --version
```

**CentOS：**

```bash
yum install -y docker
systemctl start docker
systemctl enable docker
docker --version
```

看到版本号即成功。

---

## 第三步：启动 MySQL

```bash
docker run -d \
  --name mysql8 \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=你设一个密码 \
  -v mysql_data:/var/lib/mysql \
  mysql:8.0
```

参数说明：
- `-d`：后台运行
- `-p 3306:3306`：端口映射
- `-e MYSQL_ROOT_PASSWORD=xxx`：设置 root 密码（自己记住）
- `-v mysql_data:/var/lib/mysql`：数据持久化，容器删了数据还在

验证：

```bash
docker ps
# 看到 mysql8 状态是 Up 即成功

docker exec -it mysql8 mysql -uroot -p你的密码 -e "SHOW DATABASES;"
# 能看到默认数据库列表即 OK
```

---

## 第四步：导入建表脚本

先把 `data/init.sql` 传到服务器。

**方式一：scp 上传（在本地电脑执行）**

```bash
scp d:\JavaCode\RagAgent\data\init.sql root@你的公网IP:/tmp/init.sql
```

**方式二：直接在服务器上创建**

```bash
vi /tmp/init.sql
# 按 i 进入编辑模式，把 init.sql 内容粘贴进来
# 按 Esc，输入 :wq 保存退出
```

然后导入：

```bash
docker cp /tmp/init.sql mysql8:/tmp/init.sql
docker exec -it mysql8 mysql -uroot -p你的密码 -e "source /tmp/init.sql"
```

验证：

```bash
docker exec -it mysql8 mysql -uroot -p你的密码 -e "USE rag_agent; SHOW TABLES;"
```

应看到 5 张表：`products`, `product_skus`, `product_faqs`, `product_reviews`, `cart_items`。

---

## 第五步：启动 ChromaDB

```bash
docker run -d \
  --name chromadb \
  -p 8000:8000 \
  chromadb/chroma
```

验证：

```bash
curl http://localhost:8000/api/v1/heartbeat
```

看到 `{"nanosecond heartbeat": ...}` 即成功。

---

## 第六步：安全组放行端口

**这一步不做，本地连不上服务器。**

去云服务器控制台 → 安全组 / 防火墙 → 添加入站规则：

| 端口 | 协议 | 用途 |
|------|------|------|
| 22 | TCP | SSH（一般默认已开） |
| 3306 | TCP | MySQL |
| 8000 | TCP | ChromaDB |
| 8080 | TCP | Spring Boot 后端 |

---

## 第七步：本地验证连通性

在本地终端执行：

```bash
# 测试 MySQL
mysql -h你的公网IP -uroot -p你的密码 -e "USE rag_agent; SELECT COUNT(*) FROM products;"

# 测试 ChromaDB
curl http://你的公网IP:8000/api/v1/heartbeat
```

两个都通了 → 服务器部署完成。

---

## 常用 Docker 命令

```bash
docker ps                    # 查看运行中的容器
docker ps -a                 # 查看所有容器（含停止的）
docker stop mysql8           # 停止
docker start mysql8          # 启动
docker restart mysql8        # 重启
docker logs mysql8           # 查看日志
docker logs -f mysql8        # 实时跟踪日志
docker exec -it mysql8 bash  # 进入容器内部
docker rm -f mysql8          # 强制删除容器
```
