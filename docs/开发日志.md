## 踩坑记录

### 2026-08-05 · Phase 0 启动

1. **后端无根目录 `pom.xml`** —— Maven 命令必须指定 `-f server/pom.xml`，或 `cd server` 后运行。
2. **Order 表不存在** —— `init.sql` 没有建 `orders` 表，原设计是模拟支付不落库。本次需新增订单表 + `OrderRepository`。
3. **图片静态资源已配好** —— `WebConfig.java` 已有 `/images/**` 映射，Phase 0 只需验证 URL 能否访问。
4. **Embedding 服务需先启动** —— 后端启动时若索引为空会调 `EmbeddingService`，需先跑 `server/embedding-service/start.bat`（或依赖 Spring Boot 自动拉起）。
