# AI 购物助手 — 系统概览

## 项目简介

基于 RAG（检索增强生成）的电商智能导购 AI Agent。用户通过 Android App 用自然语言描述购物需求，后端利用 LangChain4j + ChromaDB + 豆包大模型进行语义理解和商品推荐，流式返回 AI 回复与商品卡片。

## 技术栈

| 层 | 技术 |
|---|---|
| 客户端 | Android Kotlin, ViewBinding, OkHttp SSE, Glide, Coroutines |
| 后端 | Spring Boot 3.2.5, Java 17, Maven |
| AI | LangChain4j 0.36.2 + 豆包 LLM/Embedding |
| 存储 | MySQL 8.0 + ChromaDB (向量库) |

## 系统架构

```
Android App
  ├── 对话界面 (SSE 流式渲染)
  ├── 商品卡片 (嵌入对话流)
  ├── 商品详情页 (规格选择 / 评价 / FAQ)
  ├── 购物车 (SKU 支持)
  └── 用户认证 (JWT) + 历史会话

       ↕ HTTP REST + SSE

Spring Boot
  ├── ChatController → SSE 流式对话 + 标签检测
  ├── ProductController → 商品 / SKU / 评价 / FAQ
  ├── CartController → 购物车 CRUD
  ├── AuthController → 登录注册
  ├── ConversationController → 会话持久化
  ├── RecommendationController → 个性化推荐
  └── BehaviorController → 行为记录

       ↕ LangChain4j

ChromaDB (向量检索) + MySQL (结构化数据) + 豆包 API (LLM)
```

## 核心数据流

```
用户输入 "推荐油皮洗面奶"
  → 文本 Embedding → ChromaDB 语义检索 Top-3
  → System Prompt + 检索上下文 + 对话历史
  → 豆包 LLM 流式生成
  → SSE 逐字推送到 Android
  → 检测 [PRODUCT:id] 标签 → 嵌入商品卡片
  → 检测 [ADD_TO_CART:id] 标签 → 对话驱动加购
```

## 数据库

8 张表：`products`, `product_skus`, `product_reviews`, `product_faqs`, `cart_items`, `user_behaviors`, `users`, `conversations` + `messages`

## API 概览

| 模块 | 端点 | 说明 |
|------|------|------|
| 对话 | `/api/chat/stream` | SSE 流式（token/product/add_to_cart/done） |
| 商品 | `/api/products/{id}`, `/batch`, `/skus`, `/reviews`, `/faqs` | 详情 + 规格 + 评价 + FAQ |
| 购物车 | `/api/cart` | add/delete/update/set |
| 认证 | `/api/auth` | register/login/link-session |
| 会话 | `/api/conversations` | 历史会话列表/消息/删除 |
| 推荐 | `/api/recommendations`, `/api/behaviors/record` | V3 行为加权推荐 |

## 关键功能

- **RAG 管道**：Embedding → ChromaDB 检索 → Prompt 组装 → LLM 流式生成 → 三层防幻觉
- **个性化推荐**：V1 关键词 → V2 语义 → V3 行为加权（VIEW/CART/PURCHASE × 时间衰减）
- **规格选择**：淘宝风格 BottomSheet，按属性维度动态分组，交叉匹配 SKU
- **购物车 SKU**：按 (product_id, sku_id) 去重，JOIN product_skus 取规格价格
- **对话驱动购物车**：LLM 输出 `[ADD_TO_CART:id]` 标签，SSE 实时解析
- **用户认证**：JWT + BCrypt，匿名会话可迁移到登录用户
- **会话持久化**：消息写入 MySQL，product_ids JSON 还原卡片
